# lhg-sl-equity：股权结构设计

## 1. 何时使用

- 用户问"我们几个合伙人股份怎么分" → 跑三维打分。
- 用户已有分配方案（如"我们 50/50"）→ 做控制权校验与风险提示。
- 用户问"代持/对赌/期权池" → 给风险提示清单（只提示风险，不设计具体方案）。

不适用：已融资公司的老股转让定价、上市架构（VIE/红筹）——超出小白范围，提示咨询律师。

## 2. 输入与输出

**输入**：每位股东的姓名、 出资额与出资方式（货币/技术/资源/劳务）、全职或兼职、是否参与经营管理。
**输出**：
- 三维打分表 + 初始比例建议（保留 1 位小数，加总 100%）
- `cap-table.json`（见 3.4 规范）
- 控制权校验结论 + 风险提示清单（僵局/代持/对赌/退出机制）
- 末尾附声明块。

## 3. 分步方法论

### 3.1 三维打分框架（权重可调，默认 40/40/20）

| 维度 | 权重 | 打分说明 |
|---|---|---|
| 资金出资 | 40% | 按实际到账货币出资比例折算；技术/资源出资先折价再计入 |
| 人力投入 | 40% | 全职创始人 10 分，核心兼职 4~6 分，顾问 1~2 分 |
| 资源导入 | 20% | 客户、渠道、品牌、资质等可验证资源 |

计算：每人总分 = 资金分×40% + 人力分×40% + 资源分×20%，再按总分占比换算为股权比例。
**动态调整建议**：人力投入随时间变化大，建议约定"股权分期兑现（vesting）"思路——大比例一次性给足是常见坑，提示用户在股东协议中约定服务期与兑现节奏（具体条款请律师起草）。

### 3.2 控制权校验（公开常识框架，非法律标准）

- **绝对控制线**：创始人一方合计超过 2/3（如 67%），重大事项可单方通过——适合需要快速决策的早期团队。
- **相对控制线**：超过 1/2（如 51%），日常经营事项可控。
- **否决线**：超过 1/3（如 34%），对重大事项有一票否决能力——联合创始人保留此比例可防被踢出局。
- **僵局红线**：50/50 或两个 50% 左右的股东——一方不同意就什么都干不成，且无法单方解散僵局，必须标红预警。
- **一人公司线**：单一股东 ≥90%——提示"一人有限责任公司"的连带责任风险公开常识（股东不能证明财产独立时对公司债务承担连带责任），请咨询律师。

校验输出模板："创始人合计 X%，处于[绝对控制/相对控制/无控制]区间；[有/无]僵局风险。"

### 3.3 风险提示清单（必须逐条过，缺一不可）

1. **50/50 僵局**：均等分配看起来公平，是散伙纠纷最高发的结构；建议一方至少多 1% 并配套表决机制。
2. **代持风险**：隐名股东的权利主张需要证据链（出资凭证+代持协议+分红记录），显名股东擅自处分股权时维权成本高；能不代持就不代持，必须代持请律师设计全套文件。
3. **对赌风险**（如有融资计划）：业绩对赌、回购条款可能触发创始人个人连带责任；签之前必须让律师逐条过。
4. **退出机制缺失**：只谈进入不谈退出是第二大坑；股东协议中要有"退出情形 + 股权回购/转让定价原则"（定价原则请律师定）。
5. **口头约定**：所有出资与分工必须书面化，微信聊天记录只能做辅助证据。

### 3.4 cap-table.json 规范

```json
[
  {"name": "张三", "share": 60.0, "contribution": "货币30万+全职CEO"},
  {"name": "李四", "share": 25.0, "contribution": "技术入股+全职CTO"},
  {"name": "王五", "share": 15.0, "contribution": "资源导入+兼职顾问"}
]
```

- `share` 为百分比数字，保留 1 位小数。
- **硬规则**：所有 `share` 加总必须等于 100.0（允许 ±0.01 浮点误差），否则审计报 `CAPTABLE-001` blocker。
- 建议预留 10%~20% 期权池（放在创始人名下代持或增发预留，具体请律师设计）。

### 3.5 交付话术

"以上是基于三维打分的初始建议，控制权校验结论为……；风险提示共 5 条，其中标红 X 条。**本设计仅供讨论参考，落到股东协议与工商登记前，请执业律师审阅。**"

## 4. 反模式（不要这么做）

- ❌ 用户说"我们关系好，口头分一下就行"就顺着他——必须坚持书面化。
- ❌ 直接输出 50/50 不预警——僵局红线必须标红。
- ❌ 给"代持协议模板"让用户直接签——代持只提示风险，不提供成品文件。
- ❌ 承诺"这样分以后融资没问题"——融资条款因投资机构而异，不做承诺。
- ❌ cap-table 加总不是 100% 就交付——审计硬门拦截。

## 5. 自检与反馈

**质检门**：
- [ ] 三维打分表是否列出每人三项得分与换算过程？
- [ ] 控制权校验是否给出区间结论？
- [ ] 5 条风险提示是否逐条出现？
- [ ] cap-table.json 加总是否为 100.0？
- [ ] 末尾是否有声明块？是否出现承诺性表述？

**标准冒烟用例**：输入"张三出资30万全职，李四技术入股兼职"→ 输出打分表 + cap-table.json（加总100）+ 风险提示，末尾带声明。

## 附：常见问题快答

**Q1：技术入股怎么折价？**
A：先谈好技术作价多少、占多少股，写入股东协议并完成评估/出资手续；"技术无价，先干活再说"是最常见的散伙导火索。

**Q2：兼职合伙人该给多少？**
A：兼职的人力分天然低于全职，且建议"分期兑现"——先给小比例，转全职或达成里程碑再补足，避免人走了股份留下了。

**Q3：要不要预留期权池？**
A：计划融资或招核心高管的，建议预留 10%~20%；不融资的小团队可暂不设，但要在股东协议里写清"未来增发期权池时各方同比例稀释"。

**Q4：夫妻店股权怎么分？**
A：别 50/50。一方 51%+ 另一方 49%，或一方代持另一方份额（代持风险见 3.3）；家事与公司事必须分开，离婚不影响公司经营要有书面安排，请咨询律师。

**Q5：朋友只出钱不干活，给多少？**
A：纯财务投资人按出资额折股，通常不给人力分；同时约定"不参与经营决策"，避免外行指导内行。

**Q6：股权可以转让给外人吗？**
A：股东向外转让一般需要其他股东过半数同意（或其他约定），股东协议里要写清优先购买权；具体以公司章程与协议为准，请咨询律师。

**Q7：创始人中途退出，股份怎么办？**
A：靠股东协议里的退出机制：按"已兑现/未兑现"区分，已兑现部分公司回购或转让，定价原则事先写好；没写就只能协商，成本极高。

**Q8：代持一定要签代持协议吗？**
A：一定要，而且要有出资凭证、分红记录等配套证据链；但代持本身风险高，能不代持就不代持。

## 附二：术语速查表

| 术语 | 一句话解释 |
|---|---|
| 表决权 | 股东按出资比例行使的投票权，可与分红权分离约定 |
| 一票否决权 | 特定重大事项须经该股东同意，常见于 34%+ 股东 |
| Vesting（分期兑现） | 股权按服务期逐步归属，干满 4 年拿全，提前走拿部分 |
| 期权池 | 预留给未来员工/高管的股权额度，一般 10%~20% |
| 代持 | 实际出资人不出面，由他人代持股份（风险见 3.3） |
| 对赌 | 与投资人约定业绩目标，未达标创始人回购/补偿 |
| 优先购买权 | 老股东转让股权时，其他股东有优先买下的权利 |
| 回购 | 公司或创始人按约定价格买回离职股东的股权 |
| 稀释 | 增发新股后老股东比例下降，但公司估值可能上升 |
| 一致行动人 | 约定投票时保持一致的股东组合，用于集中控制权 |
