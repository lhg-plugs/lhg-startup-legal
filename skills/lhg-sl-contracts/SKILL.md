# lhg-sl-contracts：创业核心协议清单

## 1. 何时使用

- 用户问"创业要签哪些协议" → 给四类协议清单 + 每类的关键条款检查点。
- 用户拿来一份协议草稿让"帮忙看看" → 按 3.2 的检查点逐条过，输出缺失清单。
- 用户问"保密协议/竞业协议要注意什么" → 给对应检查点 + 风险提示。

不适用：要求"给我一份能直接签的股东协议"→ 明确拒绝提供成品合同，只给检查点清单；要求判断"这条款对我有没有利"→ 这是法律评价，请咨询律师。

## 2. 输入与输出

**输入**：协议类型（股东协议/合伙协议/保密协议/竞业限制协议/劳动合同/知识产权归属协议）+ 协议文本（审查场景）。
**输出**：
- 该类型协议的"关键条款检查点"清单（见 3.2）
- 审查报告：✅已覆盖 / ❌缺失 / ⚠️占位符未填，三类逐条列出
- 修改建议**方向**（如"建议补充争议解决条款，明确管辖法院或仲裁机构"），不直接写条款正文
- 末尾附声明块。

## 3. 分步方法论

### 3.1 四类核心协议总览

| 协议 | 什么时候签 | 最要命的缺失 |
|---|---|---|
| 股东协议/合伙协议 | 出资到位前，**必须先签** | 退出机制、表决机制 |
| 保密协议（NDA） | 谈合作/招人/见投资人**之前** | 保密期限、保密信息定义 |
| 竞业限制协议 | 核心员工/合伙人入职时 | 竞业范围、经济补偿 |
| 劳动合同/劳务协议 | 用工第一天起 | 合同期限、报酬、社保 |
| 知识产权归属协议 | 技术入股/外包开发时 | 职务成果归属、交付标准 |

### 3.2 关键条款检查点（审查时逐条打勾）

**A. 股东协议/合伙协议**
- [] 各方出资：金额/方式/到账时间（货币出资注明到账，技术出资注明评估方式）
- [] 股权比例与表决机制：比例、表决权计算、重大事项范围
- [] 经营管理：谁任执行董事/经理，日常决策权限
- [] 利润分配：分配条件、分配比例、分配时间
- [] 退出机制：退出情形、股权转让/回购、定价原则
- [] 违约责任：何种行为算违约、违约金/赔偿计算方式
- [] 争议解决：协商→诉讼/仲裁，写明管辖法院或仲裁机构名称
- [] 占位符检查：全文无/___/TODO/待填写

**B. 保密协议（NDA）**
- [] 保密信息定义：什么算保密信息（技术/商业/客户信息），口头披露是否需书面确认
- [] 保密期限：明确保密义务持续年限（如"协议终止后 X 年"），**不能没有**
- [] 例外情形：公开信息、 independently 开发、依法披露
- [] 使用限制：仅为合作目的使用，不得向第三方披露
- [] 违约责任：违约金或损失赔偿
- [] 争议解决：管辖法院或仲裁机构

**C. 竞业限制协议**
- [] 竞业范围：**地域范围 + 业务范围**，两者缺一不可（范围过宽可能被认定无效，提示咨询律师）
- [] 竞业期限：明确起止时间（公开常识：劳动合同法框架下一般不超过 2 年，具体请律师确认）
- [] 经济补偿：按月/按季支付标准与支付方式（**无补偿的竞业限制风险极高**，必须标红）
- [] 违约责任：违反竞业义务的违约金
- [] 争议解决：管辖法院或仲裁机构
- [] 提示：竞业限制**只约束签了协议的人**，且通常只适用于"高级管理人员、高级技术人员和其他负有保密义务的人员"

**D. 劳动合同**
- [] 合同期限：固定期限/无固定期限/以完成一定工作为期限
- [] 工作内容与工作地点
- [] 劳动报酬：金额、构成、发放时间（**不许写"面议/另行约定"后空着**）
- [] 社会保险：依法缴纳（"不缴社保"是违法约定，直接标红）
- [] 劳动保护与工作时间
- [] 保密与竞业条款（如有，链回 B/C 检查点）
- [] 争议解决：劳动争议先仲裁后诉讼的公开流程提示

**E. 知识产权归属协议**（技术入股/外包必备）
- [] 成果定义：哪些算职务成果/委托成果
- [] 权利归属：归公司所有，还是许可使用
- [] 交付标准：源代码/文档/设计稿的交付物清单
- [] 保密义务：链回 B 检查点
- [] 违约责任与争议解决

### 3.3 占位符规范

全文扫描以下占位符并逐条列出：`` `［］` `___` `TODO` `XXX` `待填写` `另行约定（未约定）`。
输出格式："第 X 条/第 X 页：未填写 → 请填写后让律师复核"。
**硬规则**：占位符不清零，审查报告结论不许写"可以通过"。

### 3.4 审查报告模板

```
协议审查报告（完整性检查，非法律意见）
协议类型：股东协议
✅ 已覆盖（6/8）：出资、股权比例、经营管理、利润分配、违约责任、争议解决
❌ 缺失（2）：退出机制、表决机制中的重大事项范围
⚠️ 占位符未填（1）：第3条

结论：完整性检查未通过，请补齐后再请执业律师审阅。
⚠️ 声明：本审查仅为条款完整性检查，非律师意见、仅供参考；签署前请执业律师审阅。
```

## 4. 反模式（不要这么做）

- ❌ 用户要"直接能签的合同范本"就给——本插件不提供成品合同，只给检查点。
- ❌ 写"这份协议没问题，可以签"——完整性通过≠条款有效，标准收尾见 3.4。
- ❌ 把缺失条款"顺手补一段标准表述"进去——只给修改方向，不写条款正文。
- ❌ 引用"《XX法》第 X 条"却没核验过——法律名称可以提，条文编号不写。
- ❌ 对"不缴社保""无补偿竞业"这类违法约定视而不见——必须标红。

## 5. 自检与反馈

**质检门**：
- [] 是否按协议类型命中了对应的检查点清单？
- [] 缺失条款是否逐条列出（不笼统说"缺几条"）？
- [] 占位符是否逐条定位？
- [] 结论是否为"请律师审阅"收尾，而非"可以签"？
- [] 末尾是否有声明块？

**标准冒烟用例**：输入一份缺"争议解决+保密期限"且带占位符的保密协议草稿 → 应报 2 条缺失 + 1 条占位符，结论为"请补齐后请律师审阅"。

**一键提 issue**：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-startup-legal/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。

## 附：常见问题快答

**Q1：口头协议有效吗？**
A：口头协议在法律上可能有效，但举证极难。创业场景一律书面化，微信确认关键事项只能做辅助。

**Q2：股东协议和公司章程哪个优先？**
A：两者都要有且不冲突；章程是工商备案的公开文件，股东协议可约定更细的内部安排，冲突时处理复杂，请咨询律师统一起草。

**Q3：保密协议签了就万事大吉？**
A：不是。NDA 防君子，核心技术还要靠专利/著作权/商业秘密组合保护；保密期限与违约责任没写清的 NDA 约等于没签。

**Q4：竞业限制没给补偿有效吗？**
A：风险极高。公开常识是竞业限制应当有经济补偿，无补偿的竞业约定很可能得不到支持；具体请咨询律师。

**Q5：劳动合同必须书面吗？**
A：是。用工之日起就应签书面合同，超过一定期限不签有双倍工资风险（公开常识），入职当天就签，不要拖。

**Q6：可以用"合作协议"代替劳动合同吗？**
A：看实质。如果是全日制用工却签合作协议，可能被认定为事实劳动关系，风险更高；用工形式要与实际一致。

**Q7：协议里写"最终解释权归公司所有"有用吗？**
A：对消费者/劳动者的格式条款中，这类表述可能被认定无效；少用霸王条款，多写清楚。

**Q8：电子签名有效吗？**
A：符合《电子签名法》要求的可靠电子签名与手写签名有同等效力；用正规电子签平台，保留签署日志。
