# lhg-sl-setup：公司设立指引

## 1. 何时使用

- 用户说"我要创业/开公司/注册个体户"，不知道选哪种主体 → 先跑本 skill 的选型问卷。
- 用户已定类型，要一份"注册流程 + 材料清单" → 直接给七步清单。
- 用户问"有限责任公司和个体户有什么区别" → 给对比表。

不适用：已成立公司的变更/注销（超出本 skill 范围，提示咨询专业人士）；外资/特殊行业准入（前置审批事项多，提示咨询律师）。

## 2. 输入与输出

**输入**：创业项目一句话 + 6 个选型问题答案（见 3.2）。
**输出**：
- 推荐主体类型 + 对比表 + 不推荐类型的理由（一句话 each）
- 注册七步清单（步骤/官方渠道/预计材料）
- 材料清单（公司章程、股东身份证明、住所证明、经营范围表述）
- 每份输出末尾附声明块（见第 6 节）。

## 3. 分步方法论

### 3.1 四类主体对比（公开常识整理，政策细节以当地为准）

| 维度 | 有限责任公司 | 合伙企业（有限合伙常用） | 个体工商户 | 个人独资企业 |
|---|---|---|---|---|
| 法律人格 | 独立法人 | 非法人组织 | 非法人（自然人经营） | 非法人 |
| 责任承担 | 股东以出资额为限承担有限责任 | 普通合伙人承担无限连带责任，有限合伙人以出资为限 | 经营者承担无限责任 | 投资人承担无限责任 |
| 典型场景 | 要融资、要招人、要做大 | 投资基金、几个合伙人分工明确 | 小店、自由职业、工作室 | 个人经营、不想设公司 |
| 注册复杂度 | 中（需章程、股东会等文件） | 中 | 低 | 低 |
| 名字要求 | 需含"有限公司/有限责任公司"字样 | 需含"合伙企业"字样 | 可用字号 | 需含"个人独资企业"字样 |
| 融资 | 可引入股东、易融资 | 可引入有限合伙人 | 难 | 难 |

> 注意：税收口径（如企业所得税/个人所得税适用）各地执行口径与优惠政策差异大，本表不展开，提示用户咨询税务师或当地税务部门。

### 3.2 选型问卷（6 问）

1. 几个创始人？是否都出资？
2. 出资方式是货币，还是技术/资源/劳务？
3. 未来 2 年是否计划融资（引入外部投资人）？
4. 能否接受经营者承担无限责任？
5. 是否需要给员工发期权/做股权激励？
6. 预计年营收规模（小店级 / 成长级 / 规模化）？

**判定规则**：
- 选"是融资/要期权/要做大"≥2 项 → 推荐有限责任公司。
- 合伙人分工明确、有人只出钱不参与经营 → 推荐有限合伙企业（出钱的做有限合伙人）。
- 一个人、小成本、试水 → 个体工商户或个人独资企业（二选一问用户偏好）。
- 出现"无限责任不可接受" → 排除个体工商户与个人独资企业。

### 3.3 注册七步清单（以有限责任公司为例，各地以官方为准）

1. **核名**：准备 3~5 个备选字号，通过当地市场监管局官网/政务服务网核名通道查询是否重名。
2. **准备材料**：公司章程、股东身份证明、法定代表人/监事身份证明、住所证明（租赁合同或房产证明）、经营范围表述。
3. **提交设立登记**：线上（政务服务网）或线下（市场监管窗口）提交，领取《营业执照》。
4. **刻章**：公章、财务章、法人章（到公安局备案的刻章点）。
5. **银行开户**：凭营业执照与章开立对公基本户（各银行要求略有差异）。
6. **税务登记/报到**：领取执照后按当地要求到税务机关报到、核定税种、领用发票。
7. **社保公积金开户**：有员工的，为单位办理社保与公积金开户（各地基数与比例不同，以当地人社/公积金中心为准）。

> 每一步标注"官方渠道"（如"XX市政务服务网—企业开办"），并写"具体入口与材料以当地最新公告为准"。

### 3.4 材料清单模板

- 公司章程（载明：公司名称住所、经营范围、注册资本、股东出资、机构职权、法定代表人）
- 股东/合伙人身份证明复印件
- 住所使用证明（租赁合同 + 产权证明，或当地认可的集群注册地址证明）
- 经营范围规范表述（参照《国民经济行业分类》，以登记机关核定为准）
- 法定代表人、监事任职文件

## 4. 反模式（不要这么做）

- ❌ 直接说"个体户最省事，你就注册个体户"——不经选型问卷就下结论。
- ❌ 给出"注册只要 3 天、费用 500 元"这类具体承诺——时限费用因地而异，必须写"以当地官方为准"。
- ❌ 帮用户编造注册地址或经营范围——这是虚假登记，明确拒绝。
- ❌ 用"包过/保证下证"等承诺性表述——触发硬门拦截。
- ❌ 把税收筹划说成"合理避税"话术——只讲公开政策口径，不教规避。

## 附：常见问题快答

**Q1：注册公司要多少钱？**
A：官方登记本身费用很低（多地已免登记费），主要成本是刻章、地址、代理记账等；具体以当地最新收费为准，不要轻信"0 元注册全包"的营销话术。

**Q2：注册资本写多少合适？**
A：认缴制下不是越大越好——写 1000 万意味着股东要对 1000 万承担出资责任。按实际经营需要写，宁小勿大，后续可增资。

**Q3：经营范围写得越多越好吗？**
A：不是。写当下要做的 + 近期可能做的即可；写太多无关项可能触发额外的许可要求，以登记机关核定为准。

**Q4：可以用住宅地址注册吗？**
A：各地政策不同，有的城市允许"住改商"（需业委会/居委会同意），有的要求商用地址；以当地市场监管部门最新规定为准。

**Q5：法人必须是大股东吗？**
A：不是。法定代表人可以是股东也可以外聘，但法人对外代表公司签字，风险高，一般由实际控制人担任。

**Q6：注册完就可以不管了吗？**
A：不行。每年要年报、按期记账报税（即使零申报也要报），长期不管会被列入经营异常名录。

**Q7：个体户需要记账报税吗？**
A：要。个体工商户同样有记账与申报义务，具体口径以当地税务规定为准。

**Q8：找代办注册靠谱吗？**
A：选择有营业执照的正规代办，合同写清服务内容与费用；营业执照、公章等原件必须自己保管，不许押在代办处。

## 附二：术语速查表

| 术语 | 一句话解释 |
|---|---|
| 认缴制 | 注册资本不用实缴到位，按章程约定的期限缴足即可（特殊行业除外） |
| 法定代表人 | 对外代表公司的人，签字即代表公司，风险最高 |
| 经营范围 | 执照上登记的业务范围，超范围经营可能被处罚 |
| 公司章程 | 公司的"宪法"，工商备案，规定组织架构与议事规则 |
| 年报 | 每年向市场监管部门报送上一年度经营情况 |
| 经营异常名录 | 没年报/失联会被列入，影响法人信用与公司经营 |
| 税务报到 | 领执照后到税务机关核定税种、领发票的手续 |
| 对公基本户 | 公司日常转账、发工资、缴税用的银行账户 |
| 社保开户 | 为员工缴纳社保前，单位要先开社保账户 |
| 前置审批 | 办执照前先拿许可证的行业（如餐饮的食品经营许可） |
